# Fonts

`NimbusSans-Regular.otf` and `NimbusSans-Bold.otf` are the URW base35 Nimbus Sans fonts from
https://github.com/ArtifexSoftware/urw-base35-fonts (AGPL-3 with a font exception, see `LICENSE` and
`COPYING`). The QC overview (step 02b) draws its text with them via the R package `showtext`, as vector outlines: the figure
looks the same on every computer, whether or not the font is installed. (The PDF therefore lists no font, and the
text in the figure cannot be selected or searched.)
